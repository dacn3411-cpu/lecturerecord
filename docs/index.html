📅 삼성 캘린더(Samsung Calendar) 자동 알림 연동

강의에서 추출된 과제 마감일과 시험 일정을 갤럭시 기본 삼성 캘린더에서 알림(1일 전, 2시간 전)으로 받으세요.

방법 A. 원클릭 iCal(.ics) 캘린더 구독 (가장 간편 · 1분 완성)

아래 캘린더 구독 주소를 복사하여 본인의 구글 캘린더 웹(calendar.google.com) → 다른 캘린더(+) → URL로 추가에 등록하세요. 갤럭시 삼성 캘린더 앱은 구글 계정과 기본 연동되어 있으므로 모든 과제/시험 알림이 갤럭시에서 자동으로 울립니다.

https://dacn3411-cpu.github.io/lecturerecord/calendar.ics
📥 현재 .ics 파일 직접 다운로드 (삼성 캘린더로 바로 열기)

방법 B. 실시간 구글/삼성 캘린더 다이렉트 Push 연동 (선택사항)

구글 캘린더 URL 구독의 갱신 주기를 기다리지 않고 녹음 분석 완료 즉시(1초 내) 삼성 캘린더에 일정을 꽂아 넣고 싶다면 GitHub Secrets에 GOOGLE_SERVICE_ACCOUNT_JSON과 GOOGLE_CALENDAR_ID를 추가하면 즉시 반영됩니다.

🤖 갤럭시 백그라운드 무인 업로드 설정 (MacroDroid)

삼성 음성 녹음 앱에서 녹음 정지 버튼을 누르는 순간, 아무 조작 없이 자동으로 GitHub에 업로드되어 분석이 시작됩니다.

📲 MacroDroid 자동화 설정 파일 다운로드

1단계: 갤럭시 음성 녹음 폴더 경로 확인

삼성 음성 녹음 앱의 기본 저장 경로는 /storage/emulated/0/Recordings/Voice Recorder/ (또는 /storage/emulated/0/Voice Recorder/) 입니다. 녹음 시 파일명을 [운영체제] 3주차 강의.m4a 처럼 저장하거나 과목별 하위 폴더에 넣으면 과목명이 자동 분류됩니다. (기본 이름인 음성 001.m4a 그대로 올려도 AI가 강의 내용을 듣고 과목명을 스스로 추론합니다!)

2단계: MacroDroid(또는 FolderSync)로 새 녹음 파일 감지 시 즉시 GitHub API 전송

  1. 갤럭시 Play 스토어에서 MacroDroid 설치
  2. 트리거(Trigger): 파일 시스템 이벤트(File System Event) → 파일 생성됨 → 폴더: Recordings/Voice Recorder
  3. 액션(Action): HTTP 요청(HTTP Request) → 메서드: PUT
  4. URL: https://api.github.com/repos/dacn3411-cpu/lecturerecord/contents/recordings/{날짜}_{파일명}
  5. 헤더: Authorization: Bearer 본인_GITHUB_PAT_토큰

🔑 모바일 웹 업로더 연결 설정

입력하신 GitHub 토큰은 외부 서버로 전송되지 않으며, 오직 현재 핸드폰 브라우저(LocalStorage)에만 안전하게 저장됩니다.

발급 방법: GitHub Settings → Developer settings → Personal access tokens (Fine-grained) → dacn3411-cpu/lecturerecord 저장소 선택 → Permissions에서 Contents: Read and write 허용

⚙️ GitHub Actions 필수 Secrets (AI 분석 & 노션 연동용)

GitHub 저장소 상단 Settings → Secrets and variables → Actions → New repository secret에 아래 항목을 등록하세요.

1. GEMINI_API_KEY (필수 · 무료 발급)

Google AI Studio (aistudio.google.com/apikey)에서 무료로 발급받은 키를 등록하세요. 1~2시간짜리 긴 강의 오디오 파일(.m4a)도 변환 없이 한 번에 인식하고 요약합니다.

2. NOTION_TOKEN & NOTION_PARENT_PAGE_ID (노션 자동 정리용)

  • 노션 API 통합(notion.so/my-integrations)에서 새 통합을 만들고 프라이빗 API 통합 시크릿을 복사해 NOTION_TOKEN으로 등록합니다.
  • 강의 노트를 모을 노션 페이지 우측 상단 ••• → 연결(Connections)에서 방금 만든 통합을 연결합니다.
  • 해당 노션 페이지 링크 끝의 32자리 ID를 NOTION_PARENT_PAGE_ID로 등록하면, 강의가 끝날 때마다 자동으로 노션 페이지와 할 일 체크리스트가 생성됩니다!
